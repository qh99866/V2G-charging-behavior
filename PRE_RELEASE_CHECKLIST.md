# Pre-release checklist

- [ ] Add final paper title to `README.md`.
- [ ] Add author names and contact information.
- [ ] Finalize `CITATION.cff` from `CITATION.cff.template`.
- [ ] Confirm and add an appropriate software `LICENSE`.
- [ ] Confirm that `data/private/analysis_data.dta` is NOT tracked by Git.
- [ ] Confirm the Data Availability wording matches the final manuscript.
- [ ] Confirm whether aggregated/derived source data may also be hosted in `source_data/` or only with the journal SI.
- [ ] Add the final Supplementary Information/source-data link after publication, if applicable.
- [ ] Review generated outputs before deciding whether any can be made public.
- [ ] Run `main_do.do` from a clean Stata session.
- [ ] Run `SI.do` from a clean Stata session.
- [ ] Check logs for errors.
- [ ] Search the repository for personal paths, credentials, and confidential identifiers.
