# Source Data

Aggregated and derived source data underlying the figures and tables are provided
with the Supplementary Information, subject to the applicable data-use agreement.

This directory is reserved for public/shareable source-data files if the applicable
data-use agreement and publication arrangements permit those files to be distributed
through this GitHub repository.

The restricted vehicle-level operational and charging records must **not** be placed
in this directory. Authorized restricted analysis data should instead be stored
locally at:

```text
data/private/analysis_data.dta
```

and are excluded from Git tracking by `.gitignore`.

If the aggregated and derived source data are distributed only through the journal's
Supplementary Information, this directory may remain empty and the final publication
link can be added here after publication.
